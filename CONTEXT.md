# HOKUNO — Brand Bible

## Identité

**Nom** : Hokuno (北の)
**Signification** : "Vers le Nord" en japonais — philosophie de toujours aller de l'avant, ne jamais s'arrêter.
**Tagline** : _Toujours aller de l'avant._
**Secteur** : Streetwear manga — parodie artistique générée par IA.
**Modèle** : Print on Demand via Printify → Shopify.

## Logos

1. **Logpose** — Une boussole (référence au log pose de One Piece). Symbole de direction, de cap à maintenir. Utilisé comme icône principale de la marque.
2. **Typographie japonaise** — ホクノ en katakana. Utilisé en branding sur les designs (visible sur les t-shirts Direction notamment).

## Positionnement

Hokuno est une marque streetwear qui revisite l'univers de One Piece à travers le prisme de la parodie, du temps qui passe et de la mythologie. Les personnages sont transformés, vieillis, divinisés ou réduits à leur silhouette — jamais reproduits à l'identique. Chaque design raconte une histoire propre à l'univers Hokuno.

Le ton est décalé, nostalgique, parfois mélancolique, toujours avec une pointe d'humour noir. On s'adresse à une génération qui a grandi avec One Piece et qui apprécie le second degré.

## Univers visuel

- Designs générés par IA et retravaillés
- Esthétique contrastée : encre noire, silhouettes fortes, couleurs signature
- Qualité graphique professionnelle, pas de rendu amateur
- Chaque collection a son propre langage visuel distinct

## Ton & Voix

- Décalé et intelligent, jamais vulgaire
- Nostalgique sans être passéiste
- Références manga subtiles — on ne nomme jamais les personnages originaux directement
- Les descriptions produit racontent une histoire, pas une fiche technique
- Le français est la langue principale, le japonais est utilisé en branding

## Collections

### 1. WANTED

**Concept** : Des avis de recherche revisités. Les personnages ont traversé 30 ans de manga — ils ont mal vieilli, ils sont épuisés, éreintés par le temps. Ils ne sont plus dangereux. Ils veulent juste que ça se termine.

**Style visuel** :
- Poster wanted sur parchemin vieilli, bords brûlés/déchirés
- "THE END" en titre (remplace le "WANTED" classique)
- Portrait du personnage transformé (vieilli, fatigué, parodié)
- Punchline **identique pour tous les personnages** : "ÇA NE FINIRA JAMAIS..." (FR) / "IT WILL NEVER END..." (EN)
- Texte secondaire (identique pour tous) : "CETTE PRIME TRAINE DEPUIS 12 ANS. HONNETEMENT, SI VOUS LE TROUVEZ DEMANDEZ-LUI SIL EST TOUJOURS PARTANT" / EN : "THIS BOUNTY HAS BEEN RUNNING FOR 12 YEARS. HONESTLY, IF YOU FIND HIM ASK HIM IF HE'S STILL UP FOR IT"
- Cachet "MARINE" en bas
- Mention "ALIVE OR DEAD"

**T-shirts** : Noir principalement (le parchemin ressort naturellement sur fond sombre).
**Couleurs dispo** : Light : White, Natural, Gravel, Red, Royal (20 variantes) — Dark : Black, Navy (8 variantes).
**Nombre de designs** : 49 personnages (17 sur Printify, 29 à créer).
**Ton** : Humour noir, fatigue existentielle, satire.

### 2. MYTHOLOGIE

**Concept** : Les ombres de l'équipage de Luffy réinventées en divinités grecques. Chaque personnage est représenté en silhouette monochrome, drapé dans une toge à la manière d'Apollon, avec une auréole divine.

**Style visuel** :
- Silhouette monochrome pleine (pas de détails internes, juste la forme)
- Toge/drapé grec
- Auréole lumineuse derrière la tête
- UNE couleur unique par personnage (sa couleur signature dans One Piece)
- Fond transparent — le design se pose sur le t-shirt

**Couleurs des silhouettes** (couleur signature par personnage) :
- Luffy → Rouge
- Zoro → Vert
- Sanji → Bleu
- Nami → Orange
- Usopp → Jaune/Doré
- Chopper → Rose
- Robin → Violet
- Franky → Cyan
- Brook → Noir/Gris
- Jinbe → Bleu marine
_(À confirmer/ajuster selon les designs finaux)_

**T-shirts** : Blanc principalement. Version inversée des couleurs disponible pour t-shirts noirs.
**Couleurs dispo** : Blanc + noir + 6-8 autres couleurs.
**Nombre de designs** : 8-10 personnages (l'équipage complet).
**Ton** : Épique, mystique, iconique.

### 3. DIRECTION

**Concept** : Les silhouettes des membres de l'équipage accompagnées d'une citation motivationnelle en français sur le thème "toujours aller de l'avant". Lien direct avec l'identité Hokuno et le logpose.

**Style visuel** :
- Silhouette noire encrée du personnage en action (pose caractéristique)
- Citation **identique pour tous les personnages** : "JE N'AI PAS BESOIN D'UN PLAN.. JUSTE D'UNE DIRECTION." (FR) — intégrée dans l'image IA, non modifiable dans Canva
- Version EN ("I DON'T NEED A PLAN.. JUST A DIRECTION.") à régénérer avec ChatGPT (texte intégré dans l'image IA, impossible à modifier)
- ホクノ (katakana) intégré au design
- Style illustration street/encre — minimaliste et graphique
- Print front ET back

**T-shirts** : Blanc principalement. Version inversée disponible pour t-shirts noirs.
**Couleurs dispo** : Light : White, Natural, Gravel, Red, Royal, Safety Pink, Sky (56 variantes) — Dark : Black, Navy (8 variantes).
**Nombre de designs** : 10 personnages (équipage complet).
**Ton** : Motivationnel, inspirant, force tranquille.

### 4. COLLECTION ÉTÉ

**Concept** : Produits saisonniers avec le logo Hokuno (Logpose + ホクノ). Accessoires et vêtements d'été pour étendre la marque au-delà des t-shirts.

**Produits** :
- Bob / bucket hat
- Casquette / dad cap
- Short / boardshort
- Débardeur

**Design** : Logo Hokuno — Logpose + ホクノ en katakana.
**Note** : Vérifier les blueprints Printify disponibles avant de créer les designs.
**Ton** : Décontracté, été, identité de marque.

## Produits

### Types de produits par design

Chaque design est décliné sur :
- **T-shirt** (produit principal) — Gildan 5000 / Printify Choice
- **Mug** — même design, adapté au format
- **Coque de téléphone** — même design, adapté au format

Le design ne change pas entre les supports, seul le cadrage/la taille s'adapte.

### Gestion des couleurs de t-shirts

- **Fond clair** (blanc + couleurs claires) : Design en version normale
- **Fond noir** : Design en version couleurs inversées (pour Direction et Mythologie). Wanted fonctionne naturellement sur noir grâce au parchemin.
- Chaque design est disponible en blanc/noir + 6-8 couleurs supplémentaires

### Langues

Chaque design textuel existe en **deux versions linguistiques** :
- **Français** (marché principal)
- **Anglais** (marché international)

Cela concerne principalement :
- **Wanted** : punchline **identique pour tous** : "ÇA NE FINIRA JAMAIS..." (FR) → "IT WILL NEVER END..." (EN)
- **Direction** : citation **identique pour tous** : "JE N'AI PAS BESOIN D'UN PLAN.. JUSTE D'UNE DIRECTION." (FR) → "I DON'T NEED A PLAN.. JUST A DIRECTION." (EN). Note : la version EN doit être régénérée avec ChatGPT (texte intégré dans l'image IA).
- **Mythologie** : pas de texte sur le design → pas de version linguistique nécessaire (une seule version universelle)

Conséquences sur le catalogue :
- Les collections Wanted et Direction ont environ **le double de SKUs** (chaque personnage × FR + EN × couleurs × supports)
- La collection Mythologie reste identique en FR et EN (designs purement visuels)
- Sur la boutique, le filtrage par langue doit être possible (tags Shopify ou sous-collections FR/EN)
- Les fiches produit (titre, description, SEO) sont traduites dans les deux langues

Dans les JSON de collection, chaque personnage contient ses textes en FR et EN dans le même objet.

## SEO & GEO (Generative Engine Optimization)

Hokuno doit être visible à la fois sur Google (SEO classique) et dans les réponses des moteurs IA — ChatGPT, Perplexity, Gemini, Google AI Overviews, Claude (GEO).

### Principes fondamentaux

Le SEO pose les fondations (crawlabilité, autorité de domaine). Le GEO ajoute une couche de structuration du contenu pour que les LLMs puissent citer Hokuno dans leurs réponses. Les deux sont complémentaires et non substituables.

### SEO technique — Shopify

**Schema JSON-LD obligatoire sur chaque type de page :**
- `Organization` : nom Hokuno, logo, réseaux sociaux, description
- `Product` : nom, prix, disponibilité, images, reviews (aggregateRating)
- `CollectionPage` : nom de collection, description, produits liés
- `BreadcrumbList` : navigation hiérarchique (Accueil > Collection > Produit)
- `Article` : pour le blog/pages éditoriales (backstories des personnages)
- `FAQPage` : FAQ par collection et FAQ globale boutique

**Fichiers techniques :**
- `robots.txt` : ne PAS bloquer les crawlers IA (ChatGPT-User, GPTBot, ClaudeBot, PerplexityBot, Google-Extended)
- `sitemap.xml` : mis à jour automatiquement par Shopify, vérifier la soumission dans Google Search Console
- `llms.txt` : fichier à la racine du site qui décrit la structure du site pour les LLMs (standard émergent 2026)

**Performance :**
- Core Web Vitals optimisés (LCP < 2.5s, CLS < 0.1) — critique avec les effets 3D/glassmorphisme
- Images : WebP/AVIF, lazy loading, srcset responsive
- Rendu serveur (SSR) pour que le contenu soit lisible par les crawlers (pas de JS-only)

### GEO — Optimisation pour les moteurs IA

**Structure du contenu (chaque page produit et collection) :**
- Première phrase = définition claire de l'entité : "Hokuno est une marque streetwear qui..."
- Blocs de réponse directe ("answer blocks") en haut de chaque page descriptive
- Données factuelles denses : prix, matériaux, tailles disponibles, origine du design
- FAQ en bas de page avec des questions formulées comme les gens les posent aux IA
- Pas de keyword stuffing — les IA valorisent la densité factuelle, pas la densité de mots-clés

**Contenu éditorial (blog Hokuno) :**
- Articles sur l'univers de chaque collection (backstories étendues)
- Guides : "Comment choisir son t-shirt manga", "L'histoire du streetwear manga"
- Mise à jour toutes les 2 semaines minimum (les citations IA décroissent après ~14 jours sans update)
- Chaque article doit inclure des sources, des données vérifiables, et des citations d'experts quand pertinent

**Présence externe (signaux off-site pour le GEO) :**
- Reddit : présence active sur r/streetwear, r/OnePiece, r/anime (les LLMs indexent fortement Reddit)
- YouTube : contenu vidéo sur la marque, les collections, le processus créatif
- LinkedIn : thought leadership sur le POD + streetwear manga
- Ces plateformes sont des sources primaires pour les LLMs — plus impactantes que les backlinks classiques pour le GEO

**Fichier `llms.txt` (à placer à la racine du site) :**

## Distribution multi-canal

Hokuno utilise Printify comme hub de production central. Les produits sont créés une seule fois dans Printify puis publiés sur plusieurs canaux de vente. Printify gère automatiquement la réception des commandes, l'impression et l'expédition quel que soit le canal d'origine.

### Canaux actifs

**1. Shopify — Canal principal (base de la marque)**
- Boutique propriétaire : contrôle total sur le branding, l'UX, le SEO/GEO
- Landing page immersive, storytelling produit, univers Hokuno complet
- Marge la plus élevée (pas de commission marketplace)
- Propriétaire de la relation client et des données
- Intégration Printify directe via app Shopify

**2. TikTok Shop — Canal d'acquisition**
- Vente directe dans les vidéos et les lives TikTok
- Les designs manga/parodie sont du contenu natif TikTok (fort potentiel viral)
- Audience jeune, internationale, fan de manga et streetwear
- Stratégie : contenu vidéo court montrant les designs, le storytelling des personnages, les behind-the-scenes
- Intégration Printify directe

**3. Etsy — Canal de découverte (phase 2)**
- Marketplace avec audience organique qui cherche activement du streetwear/art manga
- Trafic gratuit immédiat, zéro effort marketing initial
- Commissions : ~6.5% + $0.20/listing
- Bon pour valider la demande et générer les premières ventes
- Intégration Printify directe

**4. Amazon — Canal de volume (phase 3)**
- Volume massif mais marges plus faibles (~15% commission)
- Pertinent uniquement pour scaler une fois la marque établie
- Amazon possède la relation client — pas idéal pour le branding
- Intégration Printify directe

### Stratégie de déploiement

| Phase | Canal | Objectif |
|-------|-------|----------|
| Phase 1 (lancement) | Shopify + TikTok Shop | Construire la marque + acquisition virale |
| Phase 2 (+1-2 mois) | + Etsy | Trafic organique marketplace, validation produit |
| Phase 3 (scaling) | + Amazon | Volume, revenus complémentaires |

### Cohérence multi-canal

- Les descriptions produit, backstories et visuels sont identiques sur tous les canaux (source : les JSON de collection de ce repo)
- Les prix peuvent varier par canal pour absorber les commissions (marge cible identique)
- Le branding Hokuno (logo, ton, univers) doit être cohérent partout
- Shopify reste la destination finale — tous les autres canaux doivent rediriger vers la boutique Shopify quand possible

## Notes pour Claude Code

- Ce repo sert de source de vérité pour construire la boutique Shopify
- Chaque JSON de collection contient tous les personnages avec : nom, backstory, description visuelle, punchline
- Les designs sont déjà prêts dans Printify — la synchro se fait via API Printify → Shopify
- La boutique doit refléter l'univers Hokuno : landing page immersive, 3D, glassmorphisme, navigation par collection
- Ton du site : premium streetwear, pas fast fashion. Chaque produit a une histoire.
- Multilingue : FR/EN sur les designs (Wanted + Direction), fiches produit et pages du site en FR et EN
- **SEO/GEO obligatoire** : chaque page générée doit inclure le schema JSON-LD approprié, le contenu structuré pour l'extraction IA, et les meta tags optimisés
- **SSR impératif** : le contenu textuel et les données structurées doivent être dans le HTML initial, pas injecté en JS client-side uniquement
- **llms.txt** : générer et placer à la racine du site
- **robots.txt** : ne jamais bloquer GPTBot, ChatGPT-User, ClaudeBot, PerplexityBot
